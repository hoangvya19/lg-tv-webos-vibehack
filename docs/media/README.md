# Media for the README

Replace / add these files (keep the exact names). Photos straight-on, room lights low, no reflections.

| File | What to show | Size |
|---|---|---|
| `hero.jpg` | The launcher on your TV with a nice wallpaper ✅ | 1600–1920 px wide, < 1 MB |
| `home-button.gif` | Short clip: open YouTube → press Home → launcher appears ✅ (other people's content blurred) | ~6 s, 640 px wide, < 5 MB |
| `wallpaper-weather.jpg` | Close-up of the clock, date and weather over a wallpaper ✅ | 1200 px wide |
| `homebrew-settings.jpg` | Homebrew Channel → Settings with SSH Server on and Root status ok ✅ | 1200 px wide |

Video: GitHub plays `.mp4` files dragged into the README editor on github.com (up to 10 MB),
or link a YouTube video. A GIF works everywhere. Convert a phone video to GIF:
`ffmpeg -i clip.mov -vf "fps=12,scale=640:-1" home-button.gif`

Never use photos with people in them, and blur other people's content (YouTube thumbnails, ads).
